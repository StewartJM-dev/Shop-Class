# Changelog

## 0.3.0 — 2026-10-18

- Add seven 8-bit computer missions and six robotics missions under Circuit Lab, plus two working sandboxes.
- Expose computer registers, memory, carry, flags, clock transfers and a bounded original assembly interpreter.
- Add a differential-drive rover, distance and line sensors, feedback rule presets, route-command blocks, and parsed route programs.
- Preserve profile ownership, progress IDs and version 2 backups. Save programs and settings per learner; reset simulations on reopening.
- Add arithmetic, assembler, motion, sensor, mission-solution, entry, ownership and resume regression checks.


## 0.2.0 — 2026-10-18

- Merge workshop memory, a compact empty shelf, and expanded achievements into one 34-badge cabinet.
- Keep earned badges permanent, preserve earlier streak achievements, and count only known completed lessons.
- Retain fresh-profile Game Lab and My Pages sandbox entry fixes.


## 0.1.0 — 2026-10-18

- Save the current 236-entry Shop Class app as the initial GitHub baseline.
- Include six distinct workshop illustrations, 12 earned badges and per-profile project shelves.
- Include Knot Lab's 20 lessons and four tying sequences, with saved steps and corrected knot-use explanations.
- Include Python Lab's 17 challenges and playground, saved code/input, checks, readable errors, Stop and execution limits.
- Fix first-time entry to Game Lab and Web Lab sandboxes.
- Include regression checks for lesson routing, simulation goals, project ownership, badges and isolated program execution.

Browser and physical-device acceptance testing remains outstanding. Electronics depth, transistors, an interactive 8-bit computer and robotics are possible future work, not features of this baseline.
